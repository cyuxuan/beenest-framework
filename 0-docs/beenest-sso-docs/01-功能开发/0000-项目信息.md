# beenest-sso 项目结构

## 1. 模块划分

- **beenest-sso**: 父工程，负责依赖版本管理 (Spring Boot 2.5.15, Spring Cloud 2020.0.6, Spring Cloud Alibaba 2021.1)。
- **sso-sdk**: 公共 SDK 模块，用于提供给客户端应用集成的公共类或工具。
- **sso-server**: SSO 服务端核心模块，负责用户认证、注册、Token 颁发与验证。

## 3. 关键技术栈

*   **框架**: Spring Boot 2.5.15
*   **配置中心**: Nacos (Spring Cloud Alibaba)
*   **ORM**: MyBatis-Plus 3.5.3.1
*   **数据库连接池**: Druid 1.2.23
*   **数据库**: PostgreSQL
*   **鉴权**: Sa-Token 1.37.0 (Cookie 模式)
*   **加密**:
    *   JWT: JJWT 0.9.1 (HMAC-SHA256)
    *   Payload 加密: AES-128
    *   密码加密: SHA-256
*   **JSON 处理**: FastJSON2 2.0.58
