# 用户注册接口文档

## 1. 接口描述
用于新用户注册，支持账号、用户名、密码、邮箱、手机号等信息的录入。系统会对敏感信息（密码、邮箱、手机号）进行加密存储。

## 2. 接口地址
- **URL**: `/api/auth/register`
- **Method**: `POST`
- **Content-Type**: `application/json`

## 3. 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
| :--- | :--- | :--- | :--- | :--- |
| account | String | 是 | 登录账号 (唯一) | `user001` |
| username | String | 是 | 用户昵称/姓名 | `张三` |
| password | String | 是 | 登录密码 (将被SHA-256加密) | `123456` |
| email | String | 否 | 邮箱 (将被AES加密) | `test@example.com` |
| phone | String | 否 | 手机号 (将被AES加密) | `13800138000` |
| avatar | String | 否 | 头像地址 | `http://example.com/avatar.png` |

**请求示例**:
```json
{
  "account": "beenest_dev",
  "username": "BeeNest开发者",
  "password": "password123",
  "email": "dev@beenest.club",
  "phone": "13800000000",
  "avatar": ""
}
```

## 4. 响应参数

统一响应结构 `Response<T>`。

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| code | Integer | 状态码 (200: 成功, 其他: 失败) |
| message | String | 响应消息 |
| data | Object | 响应数据 (注册成功通常为 null) |

**成功响应**:
```json
{
  "code": 200,
  "message": "注册成功",
  "data": null
}
```

**失败响应**:
```json
{
  "code": 400,
  "message": "账号已存在",
  "data": null
}
```

## 5. 业务逻辑与加密说明

### 5.1 唯一性校验
- **账号 (`account`)**: 必须全局唯一，注册时会检查数据库中是否已存在该账号。
- **用户名 (`username`)**: 建议唯一，根据业务需求可配置。

### 5.2 数据加密
为了保障数据安全，写入数据库前会对以下字段进行加密处理：

1.  **密码 (`password`)**:
    - **算法**: SHA-256 (单向哈希)
    - **用途**: 登录鉴权比对。
    - **设计原因**: 密码属于绝密信息，**不需要也不应该**被还原为明文。使用单向哈希确保即使数据库泄露，攻击者也无法直接获取用户原始密码。验证时只需对比"输入密码的哈希值"与"库中存储的哈希值"是否一致即可。

2.  **敏感信息 (`email`, `phone`)**:
    - **算法**: AES (对称加密，可逆)
    - **用途**: 存储时加密，读取/展示时解密。
    - **密钥**: 使用系统配置的 AES 密钥。
    - **设计原因**: 邮箱和手机号在业务中通常需要被使用（例如发送验证码、发送邮件通知、脱敏展示等）。因此必须使用**可逆**的加密算法，以便系统在需要时能够解密出原始数据进行业务处理。

### 5.3 数据存储
- 数据存入 `sso_user` 表。
- `status` 默认为 `1` (启用)。
- `create_time` 和 `update_time` 自动生成。

## 6. 数据库设计参考
参考 `sso_user.sql` 定义：

```sql
CREATE TABLE IF NOT EXISTS sso_user (
    id BIGSERIAL PRIMARY KEY,
    account VARCHAR(50) NOT NULL UNIQUE,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(100) NOT NULL,
    email VARCHAR(100),
    phone VARCHAR(20),
    avatar VARCHAR(255),
    status INT DEFAULT 1,
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
